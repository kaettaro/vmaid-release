# VMaid ベータ手順書(公開ベータ・Windows)

VMaid は、デスクトップの隅に住む 3D のバーチャルコンパニオンです。これは、公開ベータ(動作検証・フィードバック用)の手順書です。
この ZIP に入っている素材は、**再配布できると確認できたもの**(サンプルのモデル「Alicia Solid」と、自動生成のモーション)だけです。VRoid 公式のモーションなどは入れていません(入手先は [6. 自分の素材を使う](#6-自分の素材を使う))。

- 対象 OS: **Windows 10 / 11(x64)のみ**(Mac は、このベータの対象外)
- 会話は、すべてこの PC の中で動きます(外部送信・テレメトリー・自動アップデートなし)。通信するのは、[9. 通信の一覧](#9-通信の一覧) の場合だけです
- 記載の画面の文言は、開発中のもので、少し違うことがあります。違ったら、気軽に教えてください([10. 不具合の報告](#10-不具合の報告))

## 1. 動作要件と起動

| 項目 | 目安 |
|---|---|
| OS | Windows 10 / 11(64 ビット) |
| メモリ | 16GB 以上を推奨(内蔵 AI の「Gemma 4」用)。8GB でも、軽い「Qwen3 4B」で動きます |
| 空き容量 | 本体の展開に約 1.2GB + 内蔵 AI のモデル(2.5〜5GB) |
| GPU | あれば速くなります(NVIDIA / Vulkan 対応)。なくても、CPU で動きます(返答は遅くなります) |

### 展開と起動
1. ZIP を、**日本語やスペースの少ない場所**(例: `C:\VMaid-beta\`)に展開します。OneDrive・デスクトップの同期フォルダは避けてください(大きいファイルの同期で遅くなります)
2. `VMaid\VMaid.exe` をダブルクリックします
3. 初回は「WindowsによってPCが保護されました」と出ます(署名していないため)。**「詳細情報」→「実行」** を選びます
4. 画面の右下に、透明なウィンドウが出て、タスクトレイにアイコンが出ます。**ウィンドウを閉じても、常駐したまま**です。終了は、トレイのアイコンを右クリック →「終了」です

> 起動しない・すぐ落ちるときは、[10. 不具合の報告](#10-不具合の報告) の方法で、出た文字を添えて教えてください。

## 2. 最初の設定

### 2-1. サンプルのモデルを入れる
1. 初回は、モデルが未登録なので、**設定ウィンドウが自動で開きます**(開かないときは、トレイのアイコン →「設定を開く」)
2. 「キャラクター」タブの **「モデルを選んで、キャラとして追加…」** を押します
3. ZIP の `サンプル\AliciaSolid.vrm` を選びます
4. 画面にキャラが出ます。**ドラッグで移動、ホイールで拡大・縮小**できます

自分の VRM を使うときは、同じ手順で選びます([6. 自分の素材を使う](#6-自分の素材を使う))。

### 2-2. モーション
モーションは、**自動生成の内蔵モーション**(待機・手を振る・ダンス 3 種・ふれあい用の 8 種など。[3. 基本操作](#3-基本操作)の末尾)が、最初から入っています。そのまま、会話・ふれあい・ダンスが動きます。
もっと動きを増やしたいときは、VRMA などのモーション素材を、自分で入れます([6. 自分の素材を使う](#6-自分の素材を使う))。モーションを入れたあと、「モーションのタグ」(最初から ON)でタグを付けると、ルールからタグで選んで再生できます。

### 2-3. 内蔵 AI(会話)
1. キャラを**ダブルクリック**して、話しかけます(入力欄が開く。Enter で送信、Esc で中断)
2. **初回だけ**、「AI モデルのダウンロード」の確認が出ます(モデル名・サイズ・ダウンロード元・保存先・ライセンスが出ます)。「ダウンロードする」を選ぶと、ダウンロードして、**以後は完全オフライン**で動きます
   - メモリ 16GB 以上: Gemma 4 E4B(約 5GB)が既定。それ未満: Qwen3 4B(約 2.5GB)
   - 設定 →「LLM」タブで、モデルの切り替え・追加ダウンロード・削除ができます
3. **Ollama / LM Studio など**を使うなら、設定 →「LLM」で、外部の AI(OpenAI 互換)に切り替え、接続先を書きます(例: Ollama は `http://127.0.0.1:11434/v1`)。`127.0.0.1` 以外を書くと、会話が外に出るので、警告が出ます

## 3. 基本操作

| 操作 | 動き |
|---|---|
| キャラを 1 回クリック | ふれあい(手を振る・うなずくなど。ルールで変えられます) |
| キャラの上で、ポインタを往復させる | **なでる**(頭・お腹・手など。部位ごとに反応が変わります) |
| キャラを押し続ける(0.6 秒以上) | **長押し** |
| ダブルクリック | 会話の入力欄を開く |
| ドラッグ | キャラを動かす |
| Shift + ドラッグ | キャラの向きを変える |
| ホイール | 拡大・縮小 |
| 右クリック | メニュー(設定・キャラ切り替え・表情・モーション・クリック透過・非表示・終了) |
| キャラのいない場所のクリック | 下のアプリに通ります(クリック透過) |
| **Ctrl+Alt+Shift+R** | **緊急リセット**(キャラが消えた・画面外に出た・動けないとき、初期の表示に戻します。Mod の ON/OFF は変わりません) |

### 設定ウィンドウ(右クリック →「設定を開く」)
- **キャラクター**: モデル(VRM / PMX)・名前・口調(システムプロンプト)・呼び方。複数のキャラを保存して切り替えられます
- **LLM**: 内蔵 AI / 外部 AI の切り替え
- **ルール**: 「いつ → もし → する」のルールを、フォームで編集(YAML でも編集可)
- **モーション**: 登録・取り込み・▶ で試し再生・タグ(「モーションのタグ」Mod が ON のとき)
- **履歴**: 会話履歴の閲覧・削除・書き出し
- **基本設定**: 大きさ・クリック透過・最前面・起動時の表示・緊急リセットのショートカット
- **Mod**: 機能の ON/OFF([4. Mod の基本](#4-mod-の基本))
- キャラの表情・モーフ・衣装は、右クリック →「表情・衣装パネルを開く」で、スライダーやトグルで調整できます(モデルごとに保存されます。「標準にする」で、標準の見た目を決められます)

最初から入っている**内蔵モーション**(コードで自動生成。素材ではありません): 待機・手を振る・話す・うなずく・ダンス 3 種・歩く、ふれあい用の 8 種(照れる・驚く・跳ねる・悲しむ・くすぐったがる・首をかしげる・頭を差し出す・お辞儀)。

## 4. Mod の基本

機能の追加・ルールのまとまりは、**Mod** です。設定 →「Mod」タブで、トグルで ON/OFF します。OFF にしても、データは消えません。

- **区分**
  - **公式**: アプリに入っている Mod(外部へ通信しません)
  - **コミュニティ**: `.vmaidmod` で取り込んだ Mod(ニュースなど)
  - **自作**: 自分で作った Mod(自分のルール「マイルール」を含む)
- **1 つの Mod = 1 行**です。行を開くと、説明・設定・ルール(1 つずつ ON/OFF)・モーションが出ます。Mod の設定は、すべて、その行の中にあります
- **新規インストールで ON なのは、「基本」Mod(起動のあいさつ・クリック・放置・「手を振って」)と、機能 Mod の「モーションのタグ」「追いかけ」**です。ほかは、必要なものを ON にします
- **スクリプトを含む Mod**(ニュースなど)は、「開発者向け」を ON にしたときだけ、取り込み・使用できます。取り込み時と ON にするときに、権限(通信先など)の確認が出ます。通信先は、あなたが承認したものだけで、「Mod」タブの「ログ・通信ログを見る」で、いつ何に通信したかを確認できます
- **ルールの個別 ON/OFF と、値の調整**: 各 Mod の行の中の「詳しい設定」で、間隔・秒数・セリフなどを変えられます(「初期値に戻す」あり)
- Mod の中身を編集したいときは、ルール画面で編集すると、自動で「マイルール」にコピーされ、元のルールは OFF になります

## 5. Mod ごとの手順

どの Mod も、**設定 →「Mod」→ 行のトグルを ON →(行を開いて)設定 → 試す** の流れです。以下は、「試し方」と「確認してほしい点」です。

### 5-1. 公式の機能 Mod(本体に組み込み)

#### モーション関係
| Mod | 内容 | 試し方 |
|---|---|---|
| **モーションのタグ**(最初から ON) | モーションにタグを付けて整理。ルールで「タグ」を指定して再生 | ON → 「モーション」タブに、タグ欄・絞り込み・一括タグ付けが出る |
| **足の接地補正** | 足の滑り・床へのめり込みを抑える(PMX 由来のモデルやダンスで効果) | ON/OFF して、ダンス中の足を見比べる |
| **より自由な移動** | キャラが画面内を歩く・ワープする。ルールのアクション「移動する」 | ON → 行の「試しに動かす」で、行き先(左端・右端・中央・ランダム・カーソルの近く)と「歩く」「ワープ」。「自動で歩き回る」を ON にして放置すると、ときどき動く。「範囲を設定…」で、動ける範囲を画面上でドラッグして決められる。ドラッグ・緊急リセット・Mod の OFF で止まる |
| **追いかけ**(最初から ON) | カーソルの方を向く(視線のみ / 頭と首 / 体ごと) | ON → 行の設定で、強さ・速さ・上限の角度・反応する距離を調整 |

#### 見た目
| Mod | 内容 | 試し方 |
|---|---|---|
| **美化(リアル)** / **美化(トゥーン)** | ライト・陰影・ブルームなどで、リアル寄り / アニメ調に整える。**どちらか一方だけ ON** にできる | ON → 行の設定のプリセットとスライダー。**重くなったら OFF**(ブルームを 0 にする手もあります) |
| **吹き出し拡張** | 吹き出しの形(丸い・ふわふわ・ギザギザ)・色・フォント。キャラごとに変えられる。感情・発言(「!」が多い・「?」・「…」)で、漫画のように変わる | ON → 設定で形・色・フォント。ルールの「セリフを言う」で「やったー!!」(叫び)・「えっと…」(小声)・「これ、なあに?」を試す。「感情で変える」は、AI に感情タグを頼みます(返答の最後に付くので、変わるのは言い終わってから) |
| **画面効果** | 画面全体(またはキャラの近く)に、渦巻き・ピンクの霧・ハート・脈動などを重ねる。クリックは通る | ON → ルールのアクション「画面効果を出す」。行の「画面効果を作る」で自作。**消し方**: 「画面効果を消す」・Mod の OFF・**緊急リセット(Ctrl+Alt+Shift+R)** |
| **小道具** | glb の小道具を、キャラの手・頭などに付ける(ルールの「小道具を出す」) | 小道具を持つ Mod が必要(自作向け) |

#### 声・音
| Mod | 内容 | 試し方 |
|---|---|---|
| **音声合成** | 返答を声で読み上げる(OS の音声 / VOICEVOX 互換エンジン)。口がリップシンクで動く | ON → 設定で「OS の音声」(追加の準備なし。日本語の音声が OS に入っている必要があります)、または VOICEVOX(あなたが別に入れて起動。既定の接続先 `http://127.0.0.1:50021`。「自動で起動する」も選べる) |
| **効果音(SE)** | 名前をつけた音ファイルを登録し、ルールのアクション「効果音を鳴らす」で鳴らす | ON → 行の設定で、名前と音ファイルを登録し、「試しに鳴らす」。**音ファイルは同梱していません**。自分のものを選びます |

#### 気持ち・状態
| Mod | 内容 | 試し方 |
|---|---|---|
| **親密度と気分** | キャラごとに親密度・気分を持つ。ふれあいで増え、放置で減る。ルールの条件・アクションで使える | ON → ふれあいを繰り返す。親密度の値は、ルールの条件・アクションで使える(「ルール」タブで、条件「親密度」を足して試す) |
| **状態と感情** | 名前つきの状態(開始・終了・時間で自動終了)と、感情値。AI の返答の感情タグ(`[emotion:名前]`)にも反応 | ON →  ルールで「状態を始める」。**状態に「表情・衣装のセット」を付けると、状態が終わったとき自動で戻ります** |
| **高度な触れ合い** | 部位の判定、長押し・なでる・続けて触られた、などのルール | ON → キャラの頭・手・お腹などを、なでる・長押しする。OFF だと、部位に関係ないクリックの反応だけ |

#### 取り込み(MMD・FBX・PMX)
| Mod | 内容 | 試し方 |
|---|---|---|
| **MMD 対応** | PMX(モデル)・VMD(モーション)を、そのまま読み込む(物理も動く)。VMD は VRM のキャラでも使える(取り込み時に VRMA へ変換。足 IK も焼き込む。体と表情が別ファイルなら、まとめて選ぶと 1 つになる)。PMX のキャラで VRMA も再生できる | ON → 「キャラクター」で .pmx を選ぶ(テクスチャは、PMX と同じフォルダの中)。「モーション」タブで .vmd を取り込む。**VPD と物理の細かい設定は未対応** |
| **FBX インポーター** | FBX のモーション(Mixamo など)を、VRMA に変換して取り込む | ON → 「モーション」タブで .fbx を追加 |
| **PMX インポーター(小道具)** | MMD のアクセサリなど、PMX を小道具としてキャラに付ける | 小道具を持つ Mod が必要(自作向け) |

#### 話しかけ・ゲーム
| Mod | 内容 | 試し方 |
|---|---|---|
| **話しかけ** | キャラのほうから、ときどき話しかける(あいさつ・放置・独り言)。**外部通信なし** | ON → 設定で、間隔・1 日の上限・夜間(既定: 10 分あけ・1 日 20 回・23:00〜7:00 は話さない)・「静かにして」。独り言の間隔を 1 分にすると、すぐ試せます |
| **ゲーム: ○×・コネクト 4・リバーシ・チェス** | キャラと遊ぶ。ゲームごとに別の Mod | ON → チャットで「まるばつしよう」「コネクト4しよう」「リバーシしよう」「チェスしよう」。盤面の窓をクリックするか、チャットで打つ(「5」「3の2」/「3」「真ん中」/「d3」/「e2e4」)。「もう一回」「やめる」。強さ・先攻は、行の設定 |

### 5-2. 公式の Mod(YAML のみ・素材なし)
| Mod | 内容 | 試し方 |
|---|---|---|
| **基本**(最初から ON) | 起動のあいさつ・クリックの反応・放置でダンス・「手を振って」 | 起動直後・クリック・5 分放置 |
| **ダンス** | 「ワルツを踊って」「踊って ワルツ」で、楽曲に対応するモーション + BGM を再生。「ストップ」「中止」で止める(AI には送られません) | ON → 行の「楽曲の表」に、**楽曲の名前・踊るモーション・BGM(曲ファイル)**を 1 行ずつ登録 →「試しに踊る」。**BGM は同梱していません。自分の曲ファイルを選びます**(曲の開始位置の秒数で、振り付けと合わせます)。表にない名前を入れると、同名のモーションが、BGM なしで再生されます |
| **話しかけ(AI)** | 「話しかけ」と合わせて使うと、AI が、状況に合わせて話しかける(45 分ごと・30 分の放置) | 「話しかけ」と両方 ON。AI が使えないときは、何も言いません |

### 5-3. 表情・衣装のセット
右クリック →「表情・衣装パネルを開く」。モデルの表情・モーフ・メッシュ表示が、自動でスライダー / トグルになります。セットに名前をつけて保存し、「標準にする」(★)、「標準に戻す」ができます。複数のセット(猫耳・ハート目・衣装など)を「重ねる」こともできます。

## 6. 自分の素材を使う

素材の権利と利用条件は、**各作者のもの**です。使う前に、各素材の規約(改変・変換・配信・常駐利用の可否)を確認してください。

| 素材 | 入れ方 |
|---|---|
| **VRM(モデル)** | 設定 →「キャラクター」→「モデルを選んで、キャラとして追加…」 |
| **VRMA(モーション)** | 設定 →「モーション」→ 追加(1 つ)/「フォルダからまとめて取り込む…」 |
| **BVH** | 同じ「モーション」タブで追加。**取り込み時に VRMA へ自動変換**されます |
| **FBX(Mixamo など)** | 「FBX インポーター」を ON にしてから、「モーション」タブで追加 |
| **PMX(MMD のモデル)** | 「MMD 対応」を ON にしてから、「キャラクター」で .pmx を選ぶ |
| **VMD(MMD のモーション)** | 「MMD 対応」を ON にしてから、「モーション」タブで追加(VRM のキャラでも使えます) |
| **BGM つきのダンス** | 「ダンス」Mod の「楽曲の表」に、名前・モーション・曲ファイルを登録([5-2](#5-2-公式の-modyaml-のみ素材なし)) |
| **効果音** | 「効果音(SE)」Mod の行の設定で登録 |
| **VOICEVOX** | 別に入れて起動し、「音声合成」の設定で選ぶ |

登録したモーションは、**▶ で試し再生**できます(モーションの別窓プレビューも使えます)。登録後は、ルールの「モーションを再生する」で選べます。

### 素材の入手先(紹介だけです。この ZIP には入れていません)
素材の権利・利用条件は、**各配布先で、あなた自身が確認してください**(VMaid 側では、ライセンスを確認していません)。

| 種類 | 入手先 | 備考 |
|---|---|---|
| モーション集(VRMA) | <https://github.com/test157t/VRM-Assets-Pack-For-Silly-Tavern> | 取り込みは、設定 →「モーション」→「フォルダからまとめて取り込む…」 |
| 成人向けのモーション集 | <https://github.com/test157t/Spicy-VRM-Animations> | **成人向けの内容を含みます。** 18 歳以上の方が、自己責任で。VMaid には同梱していません |
| モデル「Alicia Solid」 | <https://3d.nicovideo.jp/works/td32797> | この ZIP の `サンプル\AliciaSolid.vrm` と同じものです(ニコニコのログインが要ります) |
| VRoid 公式の VRMA(7 種) | BOOTH「VRMアニメーション 7 種セット」(ピクシブ株式会社 VRoidプロジェクト) | 規約を確認してください(二次配布は禁止のため、この ZIP には入れていません) |

## 7. コミュニティ Mod

`Mod\` フォルダの `.vmaidmod` を、設定 →「Mod」→「.vmaidmod を取り込む…」で入れます。取り込み直後は OFF です。

### ニュース(RSS)— `news-rss.vmaidmod`
読みたいニュースサイトの RSS / Atom の新着を、キャラが話します。**外部の https サイトへ通信します**(あなたが書いて、確認で許可したサイトだけ)。

1. 設定 →「Mod」タブの**一番下**にある「**開発者向け**」(スクリプトを含む Mod の導入を許す)を ON にします
2. 「コミュニティ」の「.vmaidmod を取り込む…」で `news-rss.vmaidmod` を選びます。権限の確認(赤い警告: 外部のサイトへ通信)が出ます
3. 「話しかけ」Mod を ON にします(このニュース Mod は、「話しかけ」に依存します)
4. 「ニュース(RSS)」を ON にし、行を開いて、**「フィードの URL」に、RSS の URL を 1 行に 1 つ**書きます(https のみ。最大 10)
5. 保存すると、**サイトを並べた確認ダイアログ**が出ます。「許可する」を選ぶと保存されます(「キャンセル」は保存されません。http・localhost・社内の IP は保存できません)
6. 最初の取得では、いまある記事を「既読」にするだけで、話しません。**新しい記事が出たら**、キャラが話します
7. 設定で、「1 件ずつ話題として」「まとめて新着を教える」、言い方を「AI」にする(あなたの LLM がキャラの口調で話す)、などが選べます
8. 行の「**一覧の窓を表示する**」を ON にすると、見出しの一覧の窓が出ます。見出しを押すと、キャラがその話題を話します(続けて「それってどういうこと?」と聞くと、話が続きます)。「↗」で、記事をふだんのブラウザで開きます
9. 通信の記録は、「ログ・通信ログを見る」で見られます(日時・URL・結果。会話・入力は送られません)

## 9. 通信の一覧

VMaid が通信するのは、次の場合だけです。**分析・クラッシュ送信・自動アップデートの通信は、ありません。**

| 通信 | いつ | 宛先 |
|---|---|---|
| AI モデルのダウンロード | 初回のみ・同意したとき | Hugging Face |
| 外部の AI への会話の送信 | 設定で、外部の AI(Ollama など)を選んだとき | あなたが設定したアドレス(`127.0.0.1` 以外は警告が出ます) |
| 音声合成エンジンへの読み上げ文の送信 | 「VOICEVOX 互換」を選んだとき(既定はオフ) | あなたが設定したアドレス(既定 `127.0.0.1:50021`) |
| スクリプト Mod の通信 | 「開発者向け」を ON にして、通信を宣言した Mod を、あなたが承認したとき(ニュースなど) | 承認したサイトだけ(通信ログあり) |

> 公式の Mod は、外部へ通信しません。ニュース(RSS)で通信するのは、あなたが書いたサイトだけです。そのサイトから、あなたの IP アドレスが見えます。

1. **何をしたか**(操作の順番)/ **何が起きたか** / **どうなるはずだったか**

アプリのデータの場所は、`%APPDATA%\vmaid\` です(設定・会話履歴・取り込んだ Mod・モデルなど)。
