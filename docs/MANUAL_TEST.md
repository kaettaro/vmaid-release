# 手動確認手順

Windows で試す場合は、先に [WINDOWS_TEST.md](WINDOWS_TEST.md)(必要なもの・セットアップ手順)を読んでください。

ヘッドレス環境では確認できない項目(透過ウィンドウ、GPU推論、OS差)を、実機で確認するための手順。
片方のOSでしか確認できない箇所は、該当マイルストーンの節に追記していく。

## 共通の準備
- Node.js 22.12 以上(`.nvmrc` は 22。`nvm use` で切替)
- `npm install`(Electronのバイナリ取得も `postinstall` で自動実行される)
- 注意: VS Code の統合ターミナルなど、環境変数 `ELECTRON_RUN_AS_NODE=1` が設定されているシェルでは
  Electron が Node として動き、`dev` が `does not provide an export named 'BrowserWindow'` で落ちる。
  その場合は `unset ELECTRON_RUN_AS_NODE`(Windows PowerShell は `Remove-Item Env:ELECTRON_RUN_AS_NODE`)してから起動する

## M4: 内蔵LLM(node-llama-cpp)
既定の実行方式は「内蔵」。何も設定せず、キャラをダブルクリックして話しかけると、初回だけ AI モデルのダウンロード確認が出る。

## 触った部位によるクリック反応
ルールの「クリックしたとき」に、「触った部位」(頭・胸・お腹・腰・腕・手・脚・足)と「左右」(キャラから見て左/右)を指定できる。
部位は、クリック位置から、モデルの**体の外形(頭のてっぺん〜足元)に対する割合**と、**腕・手の骨**で判定する(VRMのボーンは、モデルによって見た目の部位とずれるため、胴体・頭・脚には骨の位置を使わない)。モデル個別の特例はない。
**部位を指定したルールが動いたときは、部位を指定しない汎用の「クリック」ルールは動かない**(部位ごとの反応を優先)。部位を指定したルールが無い部位・体の外をクリックしたときは、汎用のルールが動く。
初期ルールに、頭(うれしそうにする)・手(手を振る)・お腹(くすぐったがる)を入れた。胸・腰などの反応は、初期では作っていない(汎用のリアクションが動く)。
