## 方針
- **再配布できると確認できて、条件(表示義務など)を守れるものだけ**を「配布パック」の候補にする。**確認できないもの・禁止されているものは、すべて「私用パック」**(リポジトリ・配布物に入れない)。
- 「私用パック」は、自分が使うためのもの。**書き出しは、自分の別のPCへ移すためだけ**(設定 →「パック」の専用の書き出し)。共有・再配布はしない。
- ユーザーが貼ってくれた一覧は、第三者(AIの要約)によるものだったため、**ライセンスの記述が実際と違う箇所があった**(下の「一覧との相違」)。

## 私用パックの作り方(手順)
1. **VRMA(そのまま使える)**: #1 は、BOOTH から入手(ログインが必要。私は代わりに取得できない)。#2 の GitHub のファイルは、公開リポジトリから、`node scripts/fetch-private-pack.mjs` で取得できる(私用パック「community-vrma」を、アプリのデータフォルダに作る。**固定したコミット `640fd29b…` から取得し、取得元のURL・コミット・sha256 を `pack.yaml` に記録**。リポジトリには入れない。Windows でも、同じコマンドで作れる)。`VRMA_01〜07` の内容は、BOOTH の一覧の順(全身を見せる / 挨拶 / Vサイン / 撃つ / 回る / モデルポーズ / 屈伸運動)と、実際に再生して**概ね一致を確認**した(2026-10-16。Alicia で目視)。
2. **BVH**: そのまま取り込める。設定 → モーション →「ファイルを追加」「フォルダから追加」で `.bvh` を選ぶと、取り込み時に VRMA へ自動変換する(変換結果は userData の `motions-converted/` に置く)。私用パックの `pack.yaml` でも、`motions[].file` に `.bvh` を指定できる(読み込み時に変換)。対応する形: T ポーズ・左が +X・前が +Z の骨格(A ポーズは補正する)。左右が逆の BVH は断る。
   **変換が必要なもの(VMD / FBX)**: Blender などで `.vrma` に変換してから置く(VMD は、PMX/VMD の標準対応が入るまで)。
3. 自作 Mod(再配布不可の素材を含むもの)は、アプリのデータフォルダの `mods/individual/<Mod の id>/` に置く(設定 →「Mod」から、フォルダを開ける)。
4. **別のPCへ移す**(Mac → Windows): 設定 →「パック」の「私用パックを書き出す」で `.vmaidpack` を作り、別のPCの「取り込む」で読み込む。**再配布しないこと**。
