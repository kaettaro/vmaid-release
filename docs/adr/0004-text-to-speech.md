# ADR 0004: 音声合成(TTS)とリップシンク

- 状態: **実装済み(`feat/tts`)。実エンジン・Windows は未確認**
- 日付: 2026-10-16
- 関連: `docs/SPEC.md` 3.2「音声」/ 8 / `docs/MANUAL_TEST.md`「音声」/ `docs/WINDOWS_TEST.md` §9

## 1. 決めたこと
- **本体のオプション機能(既定オフ)**にする。拡張(mod, `feat/extensions` の ADR 0001〜0003)の完成を待たない。理由: 再生・口の動き・ストリームの文区切りは、キャラウィンドウと会話の中心に入り込むため。ただし、純粋ロジックは `src/shared/tts/` に分け、将来、拡張が声のバックエンドを足せる余地を残す。
- 方式は2つ: **A. OSの音声**(`speechSynthesis`)/ **B. VOICEVOX 互換のローカルエンジン**(ユーザーが別に導入・起動)。
- **見送り**: 内蔵の音声合成エンジン(ONNX)。Piper の現行版(`piper1-gpl`)は GPL-3.0 で、依存ライセンス規則(寛容のみ)に反する。MIT の派生(`piper-plus`)は日本語対応をうたうが非公式で、品質・保守・声の入手が未確認。→ 将来の候補。

## 3. 設計
- **文の区切り**(`SentenceSplitter`): `。` `！` `？` 改行で区切り、閉じ括弧が続けば含める。区切りがないまま60文字を超えたら読点で、120文字で強制的に区切る。小数点は区切らない。
- **読み上げ用の整形**(`prepareForSpeech`): URL・コード・括弧書き(30文字まで)・絵文字・装飾記号を除く。読める文字が無ければ読まない。
- **先読みキュー**(`PrefetchQueue`): 再生中に次の文(最大2つ先)を合成。失敗した文は飛ばす。キャンセルで、待ち行列・合成・再生を止め、遅れて届いた結果は捨てる。上限(12文)を超えたら古い文から捨てる。
- **通信は main が代行**(`TtsService`): `node:http(s)` で `audio_query` → `synthesis`。リダイレクトは追わない。応答は 20MB・時間(10秒/60秒)に上限。**接続先がループバック(localhost 等)の宣言のときは、接続時の `lookup` で、名前解決の結果がループバックでなければ拒否**(DNS リバインディング対策)。ループバック以外の接続先は許可するが、設定画面に赤い警告を出す。レンダラーは直接通信しない(CSP の変更なし。再生は `AudioBufferSourceNode`)。
- **リップシンク**(`AudioMouth`): 再生中の音声を `AnalyserNode` で測り、音量(RMS)→ 口の開き(ノイズ床・平方根・開くほうが速く閉じるほうがゆっくり)。再生中は、乱数の口パクを止める。OSの音声は音量が取れないので、喋っている間だけ従来の口パクを動かす。
- **喋り中の状態**: 返答のストリームが終わっても、読み上げが終わるまで「喋り中」を続ける(`whenIdle`)。
- **自動再生**: 起動時のあいさつなど、ユーザー操作なしで声が出るため、main で `autoplay-policy: no-user-gesture-required` を設定。
- **設定**: `tts`(有効・方式・接続先・音量・`say` を読むか)と、キャラごとの `voice`(話者ID・OSの音声名・速さ・高さ)。古い設定(声なし)は既定に移行。

## 4. 通信の方針(要ユーザー確認 — `CLAUDE.md` の改定案)
現在の `CLAUDE.md` 「守ること 1」は、許可する通信を「モデルのダウンロード」と「ユーザーが設定したLLMエンドポイント」だけと定めている。VOICEVOX 互換のエンジンへの通信は、**ユーザーが設定し、既定オフ、既定の接続先は 127.0.0.1** という点で LLM エンドポイントと同じ性格だが、**文言上は例外が必要**。次の改定案を提案する(**承認後に適用。それまで `CLAUDE.md` は変更しない**):

> 1. **外部通信禁止**: 許可する通信は「モデルのダウンロード」「ユーザーが設定したLLMエンドポイント」「(音声でVOICEVOX 互換のエンジンを選んだ場合の)ユーザーが設定した音声合成エンジンのアドレス」だけ。…

README・SPEC には、この通信を明記済み(プライバシーの節)。

## 5. 未確認・既知の制限
- 実際の VOICEVOX エンジンでの動作(遅延・声の質・長文での挙動)。Windows 全般(日本語音声の有無、ファイアウォール、`autoplay-policy`)。
- OSの音声の口パクは「喋っている間だけ」(音量が取れない)。母音ごとの口形(あ・い・う・え・お)は未対応(将来、VRM の `aa/ih/ou/ee/oh`)。
- 感情・抑揚の指定(VOICEVOX の `intonationScale` など)は未対応。キャラごとの声は、話者ID・速さ・高さのみ。
- 合成の中断は、レンダラー側で結果を捨てるだけ(main の通信は、進行中のものが終わるまで続く。1文ぶんなので影響は小さい)。
- 読み上げ中に音声合成エンジンが落ちた場合は、その文を飛ばして続ける(会話は止まらない)。失敗は、キャラの近くに短く表示する(10秒に1回まで)。
