# VMaid(仮)

デスクトップの隅に住む、3Dのバーチャルコンパニオンです。
好きな VRM モデルを入れると、そのキャラクターが画面の上で動き、話しかけると答えてくれます。
(MOD設定でPMX(mmd)やfbxなどのモデル対応も可能です。)

- **会話は、このPCの中だけで完結します。** 内蔵のAIが動くので、アカウントも外部サービスも要りません。会話の内容は外部に送信されません。自動アップデートなどもありません。
- **モデル・モーション・AIを、自由に入れ替えられます。** VRM(3Dモデル)、VRMA(モーション)、AI(内蔵のモデル、または Ollama / LM Studio など)を、自分で選べます。
- **「if-then ルール」で、キャラの動きを自由に決められます。** 「放置するとダンスする」「『ダンスして』と言うと踊る」のようなルールを、画面で追加できます。
- Windows と macOS に対応しています。

> 現在は**公開ベータ**です(Windows のみ配布。動作検証・フィードバック用)。アプリの名前は仮称です。ライセンスは MIT です。

## 使いはじめる

### インストール
- **Windows(x64)**: GitHub の Releases から `VMaid-beta-<version>-win.zip` をダウンロードし、展開して、`VMaidVMaid.exe` を実行します(インストーラはありません)。詳しい手順は、ZIP に入っている「ベータ手順書」([docs/BETA_GUIDE.md](docs/BETA_GUIDE.md))にあります。
- **macOS(Apple Silicon)**: このベータでは、配布していません(ソースからビルドできます。[docs/DISTRIBUTION.md](docs/DISTRIBUTION.md))。

> まだ署名されていないため、初回に OS の警告が出ます。
> - macOS: アプリを **右クリック(Control+クリック)→ 開く** で起動してください。
> - Windows: 「WindowsによってPCが保護されました」と出たら、**詳細情報 → 実行**を選んでください。

### 最初の設定
1. 初回は設定ウィンドウが開きます。「キャラクター」タブの**「モデルを選んで、キャラとして追加…」**で、ZIP の `SampleAliciaSolid.vrm`、またはお持ちの `.vrm` ファイルを選びます。
2. 待機・クリック・ダンスなどの基本のモーション(自動生成)は、最初から入っています。モーション素材を足したいときは、手順書の「自分の素材を使う」を見てください。
3. キャラを**ダブルクリック**して話しかけてください。**初回だけ**、AIモデル(約2.5〜5GB)のダウンロード確認が出ます。同意すると、ダウンロードして、以後は完全オフラインで動きます。

### 操作
| 操作 | 動き |
|---|---|
| キャラを1回クリック | ふれあい(手を振る、うなずくなど。ルールで変えられます) |
| キャラの上で、ポインタを往復させる(なでる) | **なでる**: 頭・お腹・手など、同じ部位の上で、マウスを往復させると反応する(なでている秒数で、反応が段階的に変わる) |
| キャラを押し続ける(動かさずに0.6秒以上) | **長押し** |
| キャラをダブルクリック | 会話の入力欄が開く(Enterで送信、Escで中断) |
| ドラッグ | キャラを動かす |
| Shift を押しながらドラッグ | キャラの向きを変える(横方向=左右、縦方向=上下の傾き。45°刻みの近くで吸着。回しても足元・頭は窓から出ない。モデルごとに保存) |
| ホイール(2本指スクロール) | 拡大・縮小 |
| 右クリック | メニュー(キャラを切り替え・モデル・表情・衣装パネル・モーション・ルール・設定・クリック透過・非表示・終了) |
| キャラのいない場所のクリック | 下のアプリに通ります(クリック透過。メニューでオフにもできます) |
| メニューバー(Windowsはタスクトレイ)のアイコン | 表示/非表示・設定・終了。ウィンドウを閉じても、常駐したままです |

### 設定画面(右クリック →「設定を開く」)
- **LLM**: 内蔵のAI(既定)と、Ollama などの外部AI(OpenAI互換)を切り替えます。内蔵AIのモデルの選択・ダウンロード・削除もここです。
- **キャラクター**: モデル(VRM)+名前・口調・性格(システムプロンプト)・あなたの呼び方を、**複数のキャラとして保存**できます。切り替えは、ここか、右クリック →「キャラを切り替え」から(毎回ファイルを選び直す必要はありません)。会話の履歴と話し方は、キャラごとに分かれます。ルールは、ルールごとに「対象のキャラ」を選べます(選ばなければ全員)。「モデルを選ぶ…」で選んだモデルは、自動でキャラとして登録されます。
- **ルール**: キャラの動きのルール(いつ → もし → する)を、フォームで編集します。YAMLでも編集でき、書き出し・取り込み(共有)もできます。
- **履歴**: 会話履歴の保存のオン/オフ、削除、書き出し(JSON / テキスト)。
- 右クリック →「表情・衣装パネルを開く」で、表情・モーフ・メッシュの表示を、スライダーで調整できます(モデルごとに保存されます)。

### 「ルール」の例
初期のルールが入っています。`設定 → ルール` で、見ながら変更できます。
- 起動したとき、あいさつする
- 5分放置すると、ダンスする(確率80%・10分に1回まで)
- 「ダンスして」「踊って」と入力すると、踊る(**AIには送られません**)
- 「手を振って」「バイバイ」と入力すると、手を振る

## Mod(機能の ON/OFF)
設定 →「Mod」で、機能を足したり、ルール・モーションをまとめたものを、トグルで ON/OFF できます。
- **公式の機能 Mod**(アプリに同梱): モーションのタグ・足の接地補正・音声合成・効果音・美化・追いかけ・吹き出し拡張・より自由な移動・MMD 対応・FBX インポーター・ゲーム・話しかけ・親密度と気分・高度な触れ合い、など。新しくインストールしたときは、**「モーションのタグ」と「追いかけ」だけ ON**(あとは OFF)です。以前から使っていた方は、使っていた機能が、そのまま ON になります。OFF にしても、保存したデータは消えず、ON に戻すと元どおりです。
- **ルール・モーションの Mod**: ルールとモーションをまとめたもの(置き場所で、公式・コミュニティ・自作に分かれます)。`.vmaidmod` で、書き出し・取り込みができます。取り込むときに中身を確認し、追加した直後は OFF です。コードを含まないものは、通信もしません。
- **スクリプトを含む Mod**(上級者向け): 「開発者向け」を ON にしたときだけ、取り込み・使用できます。権限(通信先など)を日本語で確認してから ON にし、サンドボックスの中で動きます。作り方は `docs/guides/mod-authoring.md`。例として、ローカルの text-to-vrma から、入力した文章で、モーションを作る Mod が `examples/mods/motion-gen-textvrma/` にあります(導入は `docs/guides/motion-gen-setup.md`。text-to-vrma は同梱しません)。連携できる外部ツールの一覧は `docs/EXTERNAL_TOOLS.md`。
- **緊急リセット**: キャラが消えた・画面の外に出た・Mod の効果で動けない、というときに、ホットキー **Ctrl+Alt+Shift+R**(Mac は Cmd+Option+Shift+R。基本設定で変えられます)・トレイアイコン・右クリックメニューで、キャラを初期の表示(表示・右下・大きさ 100%・クリック透過 OFF)に戻し、ルールの効果・向き・モーションも初期に戻せます。保存した設定と Mod の ON/OFF は、変わりません。
- 公式のリポジトリ・本体には、成人向けのモーション・指示文は同梱しません。他の人が作った Mod の内容と利用の責任は、利用者にあります(`docs/TERMS.md`)。

## MMD(PMX / VMD)の素材を使いたいとき
公式の機能 Mod「MMD 対応」を ON にすると、PMX(モデル)と VMD(モーション)を、そのまま読み込めます(Bullet 物理も動きます)。VMD は VRM のキャラでも使えます(取り込み時に VRMA へ変換)。VPD(ポーズ)と、物理の細かい設定は、未対応です。経緯と制限は [docs/MMD_FEASIBILITY.md](docs/MMD_FEASIBILITY.md) を見てください。
**元の素材の利用条件は、変換しても、読み込んでも、なくなりません。** 改変・別形式への変換・配信・デスクトップ常駐での利用の可否は、**各モデル・モーションの規約**で確認してください。

## ふれあいの拡張
**ふれあいのルール**(設定 →「ルール」): 「クリック」に加えて、**なでる・長押し・なで終わり**のトリガー、**続けて触られた・親密度・気分**の条件、**待つ・親密度を変える・気分を変える**のアクション、モーションの**ループ再生・連続再生**が使えます(「高度な触れ合い」「親密度と気分」の Mod を ON にします)。親密度(0〜100)と気分は、キャラごとに保存され、ふれあいで増え、放置でゆっくり減ります。

## 音声(キャラが声を出す・既定はオフ)
設定 →「Mod」の「音声合成」を ON にすると、キャラが返答を声に出します。**既定はオフ**で、オンにしない限り何も変わりません。
- **OSの音声**: 追加の準備は不要です。日本語の音声が、OSに入っている必要があります(Mac では確認済み。Windows は未確認)。
- **VOICEVOX 互換のエンジン**: [VOICEVOX](https://voicevox.hiroshiba.jp/) などを、**あなたが別に入れて起動**します(VMaid は同梱も自動ダウンロードもしません)。既定の接続先は `http://127.0.0.1:50021` です。声ごとの利用規約・エンジンのライセンスは、各自で確認してください。
- 声は、**キャラごと**に選べます(速さ・高さも)。口は、声の大きさに合わせて動きます(リップシンク)。
- 返答は、文が完成するたびに読み上げます(全文を待ちません)。Esc や新しい入力で止まります。ルールの「セリフを言う」も、設定でオンなら声に出します。

## プライバシー
- 通信するのは、次の2つだけです(**音声の「VOICEVOX 互換のエンジン」を使う場合は、③ が加わります**)。それ以外の通信は、一切ありません。
  1. **AIモデルのダウンロード**(初回のみ・同意後。配布元: Hugging Face)。
  2. **あなたが設定したAIのアドレス**(外部のAIを使う場合のみ。既定の内蔵AIは通信しません)。
  3. (音声でVOICEVOX 互換のエンジンを選んだ場合のみ)**あなたが設定したエンジンのアドレス**。既定は、あなたのPC内(`127.0.0.1`)で、読み上げる文だけを送ります。PCの外のアドレスを設定すると、設定画面に警告が出ます。
- 会話履歴は、このPCの中(`rules.yaml` などと同じ、アプリのデータフォルダ)にだけ保存されます。設定画面から、いつでも削除・書き出しができます。
- アプリのデータフォルダ: macOS は `~/Library/Application Support/vmaid/`、Windows は `%APPDATA%\vmaid\`。

## 開発者向け
- 技術: Electron + TypeScript、React、Three.js + `@pixiv/three-vrm`、`node-llama-cpp`
- 前提: Node.js 22.12 以上(`.nvmrc`)。VS Code のターミナルなどで `ELECTRON_RUN_AS_NODE` が設定されていると、Electron が起動しないため、`unset ELECTRON_RUN_AS_NODE` してください。

```bash
npm install
npm run dev          # 開発起動
npm test             # テスト(Vitest)
npm run typecheck    # 型チェック
npm run lint         # Lint
npm run build:dir    # 動作確認用のパッケージ(release/)
npm run build:mac    # macOS の dmg
npm run build:win    # Windows のインストーラ(Windows でビルド)
```

- Windows で試す手順(必要なもの・セットアップ・確認ポイント): [docs/WINDOWS_TEST.md](docs/WINDOWS_TEST.md)
- 実機での確認項目(Mac / Windows): [docs/MANUAL_TEST.md](docs/MANUAL_TEST.md)
- ビルド・署名・公開: [docs/DISTRIBUTION.md](docs/DISTRIBUTION.md)

- ロジックは、Electron に依存しない純粋な TypeScript として `src/shared/` に置き、テストします。
